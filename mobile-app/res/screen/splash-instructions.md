# Splash Screen Instructions

This directory should contain splash screen images for different device resolutions. The splash screens should follow this naming convention:

## Android
- `android/screen-ldpi-portrait.png` (320x426)
- `android/screen-mdpi-portrait.png` (320x470)
- `android/screen-hdpi-portrait.png` (480x640)
- `android/screen-xhdpi-portrait.png` (720x960)
- `android/screen-xxhdpi-portrait.png` (960x1600)
- `android/screen-xxxhdpi-portrait.png` (1280x1920)
- `android/screen-ldpi-landscape.png` (426x320)
- `android/screen-mdpi-landscape.png` (470x320)
- `android/screen-hdpi-landscape.png` (640x480)
- `android/screen-xhdpi-landscape.png` (960x720)
- `android/screen-xxhdpi-landscape.png` (1600x960)
- `android/screen-xxxhdpi-landscape.png` (1920x1280)

The splash screen images for this project have been automatically generated based on the app icon. For a better visual experience, consider creating custom splash screens with a centered logo on a solid background.

## Creating Custom Splash Screens

To create custom splash screens:

1. Start with a solid background color (#343a40 for this app)
2. Add the app logo in the center, sized appropriately for each resolution
3. Add a subtle loading indicator or text if desired
4. Save in PNG format with the correct naming convention
